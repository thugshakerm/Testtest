# Revival image assets

This directory contains **5,764 unique image files** representing **10,737 original repository paths** from the six deeply studied revival sources. Exact duplicate binaries are stored once by SHA-256; `manifest.json` maps every original source path to its local content-addressed file.

Sources: Kapish/Tadah legacy, Tadah rewrite, Finobe, Fobe/Alphaland, Hexagon, and BubbaBlox v2. Filenames are SHA-256 hashes to prevent collisions and preserve deduplication. Repository licenses still apply.
